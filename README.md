# Тестовое задание - ITLINE

**Стек**: Java 17, Spring Boot 3.5.16, PostgreSQL 16.

**Запуск**: `docker compose up -d`, `./mvnw spring-boot:run`

### Описание проекта

1. Приложение на **Spring Boot**: страница со списком записей, добавление и удаление, хранение в PostgreSQL.
2. Фронтенд-клиент на базе статики.
